# UIKit console starter

Generated by `uikit init`. This is a **starter**, not a framework: it shows the
minimum wiring for an out-of-the-box console page.

## 1. Install

```bash
pnpm add @lynxland/uikit @lynxland/uikit-preset-console @tanstack/react-query \
  @tanstack/react-router @tanstack/react-form @tanstack/react-table
```

## 2. Mount the provider and styles

```tsx
import { PresetProvider } from "@lynxland/uikit";
import "@lynxland/uikit/preset.css";

<QueryClientProvider client={queryClient}>
  <PresetProvider>
    <RouterProvider router={router} />
  </PresetProvider>
</QueryClientProvider>;
```

## 3. Define a source

`src/lib/widgets.ts` should export `widgets`, `widgetFields` and `widgetFilters`.
See `docs/page-templates/collection-page.md` for the shape:

```ts
export const widgets = collectionSource<Widget>({
  name: "widgets",
  async read(request, ctx, signal) {
    return api.listWidgets(request, ctx.projectId, signal);
  },
});
```

## 4. Wire `src/uikit-starter.tsx`

Add the route with `validateSearch: widgetsSearch.schema` and the core
`parseSearch` / `stringifySearch` serializer.

Then delete `uikit.config.json` if you do not need it; nothing consumes it.
